# Thực hành tạo CSDL bằng MySQL Workbench

## Mục tiêu
Tạo cơ sở dữ liệu MySQL bằng giao diện Workbench và câu lệnh SQL.

## Cách 1: Workbench
1. Mở MySQL Workbench và kết nối tới MySQL Server.
2. Trong vùng **SCHEMAS**, nhấn biểu tượng tạo Schema mới.
3. Nhập tên `my_database1`, chọn **Apply**, xác nhận và **Finish**.

## Cách 2: SQL
1. Mở **New Query Tab**.
2. Mở tệp `create_database.sql`, chạy các câu lệnh bằng nút tia sét.
3. Làm mới SCHEMAS, kiểm tra `my_database1` đã xuất hiện.

> Đây là mã nguồn mẫu để thực hành. Chỉ ghi nhận đã hoàn thành sau khi chạy và kiểm tra trực tiếp trên MySQL Workbench.
